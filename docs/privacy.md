# Privacy

Context is designed to stay on your Mac.

## What we contact

- GitHub Releases (optional) when you check for updates.
- Websites you open via link cells, and favicon/preview fetches for those links when enabled.

There is no analytics or telemetry endpoint in this project.

## Clipboard

History is stored locally while the Clipboard widget is present. Password-manager private copies should be skipped when marked by the system. Clearing history or removing the widget deletes saved entries.

## AI widgets

AI Usage and AI Activity do not read conversations, prompts, or generated code. Optional API keys are stored in a Context Keychain entry.

## Permissions

Location, Bluetooth, pasteboard, Automation, and Accessibility are requested only when you add a widget that needs them.
