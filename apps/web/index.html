    Record it in one go.

    Right-click an item and choose Assign Shortcut. The keys appear as you press them, and Context tells you if macOS or another item already uses them.

    Every shortcut in one list.

    Settings → Items shows each shortcut beside its item. A warning marks one that another app has taken; click it to pick new keys.

    Stats, in the dock and in a window.

    The dock shows the numbers you choose. Click them for the full picture of your Mac: nine sections, refreshed every 1, 2 or 5 seconds, paused whenever you like.

      Pick one or more. Fewer metrics make the widget shorter. RAM is working memory; SSD is used space on the startup disk.

      Every widget opens a card.

      Hover a widget in the dock and its card slides out, with the controls inside it. Click Clipboard, Stats or your AI widgets to open their full window.

      Arrange it by hand.

      No setup screens needed. Everything happens by dragging, right on the dock. Settings has the same controls if you prefer a list.

      Make it yours.

      Where it sits, how it shows up and what it is made of, all from Settings → Appearance.

      Private by design.

      Context works on your Mac. Optional update checks hit GitHub Releases. Widget polling runs only while the widget is in use.

      No telemetry
      There is no analytics endpoint. Stats reads your hardware directly and never terminates processes.
      Your AI work stays yours
      AI Usage and AI Activity never read conversations, prompts or generated code. Optional API keys are saved in Context’s own Keychain entry.
      Your clipboard stays on your Mac
      History is saved locally while the Clipboard widget is in your dock. Clear History or remove the widget to delete it. Copies marked private by password managers are skipped. Website icons and selected link previews contact the relevant websites.
      Nothing typed is recorded
      Keyboard Cleaner only blocks keys while cleaning, and the lock is never saved.
      You grant each permission
      Location, Bluetooth, paste access, Automation for Spotify or Music and Accessibility are asked for only when you add the widget that uses them.

      Frequently asked questions.

      What is Context?
      A second dock for the edge of your Mac. It keeps apps, web links and live widgets in reach while you work.
      Which Macs can run it?
      Context requires macOS 15 or later.
      What can I put in the dock?
      Up to twelve apps, links and widgets. Widgets include clipboard history, weather, a Mini Player, Bluetooth, Stats, AI Usage and AI Activity.
      Does clipboard history survive a restart?
      Yes. Text, links and images are saved locally; file entries point to their original files. History keeps up to 200 entries, including the newest 12 copied images. Clear History or removing the Clipboard widget deletes the saved history.
      Can I open things from the keyboard?
      Yes. Give any app, link or widget a shortcut from its right-click menu or Settings → Items. Shortcuts work from any app, and Context needs no Accessibility or Input Monitoring access for them.
      Is Context free?
      Yes. Context is free and open source.
      Does Context read my AI conversations?
      No. AI Usage and AI Activity do not read conversations, prompts or generated code. Optional API keys are stored in Context’s own Keychain entry.
      When does Context ask for permissions?
      Only when you add a widget that needs them, such as paste access for clipboard history, Location for weather, Bluetooth, Automation for music or Accessibility for Keyboard Cleaner.
